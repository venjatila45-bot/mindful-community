MINDFUL COMMUNITY - PWA STARTER
Unzip the folder and open index.html to try the responsive demo.
To enable PWA install/offline features, publish it over HTTPS or serve it from localhost; opening index.html directly will not enable service workers.
For iPhone: open the published HTTPS website in Safari, tap Share > Add to Home Screen, then Add.
IMPORTANT: This is a front-end prototype. Profiles, posts and likes are saved only in this browser. They are not shared with other people. It has no real authentication, shared database, real-time messaging, payment processing, or secure cloud photo storage. Do not collect sensitive information or use as a production community until a secure backend and access policies are added and tested.
